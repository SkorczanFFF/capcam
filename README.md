# CapCam

Head tracking for PC racing games using an Android phone mounted on a cap.
The phone streams its rotation over UDP. On the PC, games with TrackIR support get it through
[opentrack](https://github.com/opentrack/opentrack); BeamNG.drive also gets its own mod.

Planned games: BeamNG.drive, Assetto Corsa, ACC / AC EVO / AC Rally, Richard Burns Rally (RSF).

Work in progress.
